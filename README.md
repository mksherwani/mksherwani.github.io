📄 Personal Website Portfolio
A modern, responsive personal portfolio built with HTML5, Bootstrap 5, and animated Canvas backgrounds.

🌟 Features
Unified Design System: Uses a central css/style.css and css/script.js to ensure consistent dark theme, typography, and animations across all pages.
Neural Network Animation: An interactive canvas background representing AI/Data nodes connecting in real-time.
Glassmorphism: Frosted-glass cards (glass-card) that provide depth and readability against the dark theme.
Responsive Design: Fully mobile-optimized using Bootstrap 5 grid system.
AOS Animations: Scroll-triggered entry animations for a smooth user experience.
## Overview

This website serves as an online presence.  

It includes sections for:
- **Research:** An overview of research projects.
- **People:** Information about team members or collaborators.
- **Publications:** A list of scholarly outputs.
